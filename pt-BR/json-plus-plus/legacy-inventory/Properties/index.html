Observações​

  • JSON Initialization Mode escolhe objeto vazio ou array vazio.
  • Default JSON Path guarda o caminho inicial; use as Actions de arquivo para carregar/salvar explicitamente.
  • Enable Auto Load, Enable Auto Save e Read Only são lidas na criação; essa leitura não garante carregamento/salvamento automático ou bloqueio de toda mutação em todas as plataformas.
  • File Encoding é lido; o descritor oferece apenas UTF-8.
  • Enable Debug Mode controla o detalhamento associado às mensagens de erro.
  • Minify, Backup Original File, Navigate Only If Object Exists, Enable Logging e Enable Log Error são lidas ao criar instância.
  • As demais opções visíveis não são carregadas ativamente na criação atual. Isso inclui esquema JSON, criptografia, multithreading, coleta de dados e campos de teste. Não conte com efeito funcional delas.
  • TESTE é multilinha e não tem comportamento associado no runtime.
