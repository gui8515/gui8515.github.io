A57 — Carregar JSON de uma string

Descrição​

Analisa o texto fornecido como JSON e substitui o valor JSON atual do objeto quando a análise é bem-sucedida.

Quando usar​

Use esta ação quando o texto JSON já estiver disponível em uma expressão, variável string ou outro resultado de evento. Use Carregar JSON de um arquivo quando a entrada precisar ser lida de um arquivo.

Sintaxe​

JSON++ Object : Load JSON from String <jsonText>

Anatomia​

jsonText é o documento JSON completo a analisar. O documento pode ser um objeto JSON, array ou outro valor JSON válido aceito pelo analisador.

Parâmetros​

PosiçãoNomeTipo no descritorSignificadoValores aceitos / restrições
1jsonTextTextDocumento de entradaDeve ser JSON válido para a substituição ser bem-sucedida.

Comportamento​

A implementação nativa converte o texto do Fusion para UTF-8 e o analisa. Em caso de sucesso, atribui o valor analisado e gera a condição de ID 57 (On JSON Loaded). Uma falha de análise ou exceção JSON informa erro por On Error; a atribuição e o gatilho de carregamento ocorrem somente após uma análise bem-sucedida.

Exemplos​

* Start of Frame
    JSON++ Object : Load JSON from String "{""player"":{""name"":""Alex""}}"

* JSON++ Object: On JSON Loaded
    String : Set alterable string to GetString( "JSON++ Object", "/player/name" )

Resultado esperado​

Após o carregamento bem-sucedido, /player/name é a string Alex e o gatilho On JSON Loaded é executado.

Erros e casos especiais​

  • JSON inválido não gera On JSON Loaded na implementação nativa inspecionada.
  • Esta referência não afirma que todas as extensões JSON ou comentários são aceitos; o código-fonte chama o analisador da biblioteca JSON sem uma opção permissiva documentada.
  • O comportamento não foi validado em runtime aqui para cada plataforma.

Limitações​

A função nativa inspecionada substitui o JSON sem redefinir navegação/histórico. HTML5 limpa seu buffer de inserção e redefine currentPath para a raiz. Portanto, a redefinição de estado não é uniforme entre runtimes.

Compatibilidade de plataformas​

Foram inspecionados o código-fonte nativo C++ compartilhado e o código HTML5 separado. Isso não constitui validação em runtime de uma aplicação exportada; as diferenças de implementação estão documentadas acima.
