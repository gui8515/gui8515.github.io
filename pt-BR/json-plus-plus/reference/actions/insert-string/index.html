Inserir string

Descrição​

Insere o texto fornecido como um valor string JSON.

Quando usar​

Use para nomes, rótulos, identificadores e outros textos. Use Insert Number para dados numéricos que devam permanecer numéricos no JSON.

Sintaxe​

JSON++ Object : Insert string <value> at <path> with key <key>

Anatomia​

Os argumentos da ação seguem a ordem path, key, value.

Parâmetros​

PosiçãoNomeTipoSignificadoValores aceitos / restrições
1pathTextLocal paiCaminho JSON Pointer; um caminho vazio ou / seleciona a raiz.
2keyTextNome do membro do objetoUsado para destinos do tipo objeto; ignorado para destinos do tipo array.
3valueTextConteúdo da stringArmazenado como texto; não é analisado como JSON.

Comportamento​

No modo padrão Immediate, o valor substitui o membro do objeto com a mesma chave ou é acrescentado a um destino do tipo array. O alvo nativo converte o texto recebido do Fusion para UTF-8 para inserção. Uma ramificação de destino ausente pode ser inicializada como objeto.

Exemplos​

* Start of Frame
    JSON++ Object : Insert string "Alex" at "/" with key "name"

Resultado esperado​

A raiz passa a ser {"name":"Alex"}.

Erros e casos especiais​

  • O texto é armazenado como string JSON; textos como 42 permanecem entre aspas no JSON serializado.
  • Destinos do tipo array acrescentam a string e ignoram a chave fornecida.
  • Erros de caminho são informados por On Error.

Limitações​

A ação armazena o conteúdo literal da string e não analisa esse texto como JSON.
