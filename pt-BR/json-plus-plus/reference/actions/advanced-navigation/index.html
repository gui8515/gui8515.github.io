Navegação avançada

Descrição​

Use a navegação avançada quando precisar de opções adicionais; para um caminho absoluto existente, prefira Definir caminho atual. No editor de eventos do Fusion, a legenda desta ação é Navigate to %0 with advanced options.

Quando usar​

Use a navegação avançada quando precisar de opções adicionais; para um caminho absoluto existente, prefira Definir caminho atual.

Sintaxe​

JSON++ Object : Navigate to <path> with advanced options (mode: <mode>)

Anatomia​

O rótulo do objeto seleciona a instância. %0, %1 e os marcadores posteriores da legenda são substituições contadas a partir de zero, não entrada literal. Os argumentos seguem a tabela posicional, mesmo quando sua ordem visual na legenda difere.

Parâmetros​

PosiçãoNomeTipoSignificado e restrições
1pathTextCaminho de destino, por exemplo /player. Sem padrão declarado.
2modeTextTexto: relative,absolute,append; este argumento é ignorado. Sem padrão declarado.

Comportamento​

O nativo resolve o caminho independentemente de mode. Caso contrário, define o cursor, acrescenta o novo cursor ao histórico habilitado sem limitá-lo nesta função e emite Ao definir o caminho atual/O caminho foi definido.

Exemplos​

Cenário básico, documento inicial:

{"player":{"hp":100}}

Primeiro carregue este documento com Carregar JSON de uma string.

Resultado esperado​

O cursor nativo passa a ser /player se a proteção permitir.

Erros e casos especiais​

O nativo captura localmente apenas JSON parse_error. O aviso de mesmo pai pode emitir erros duplicados e ainda alterar o cursor.

Limitações​

HTML5 usa modos numéricos estritos 0=set,1=enter,2=leave,3=root.
