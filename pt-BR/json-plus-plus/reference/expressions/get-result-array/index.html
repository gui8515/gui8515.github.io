Obter array do resultado

Descrição​

Serializa o resultado selecionado somente quando ele é um array.

Quando usar​

Leia depois de uma busca bem-sucedida, consultando a lista de resultados armazenada. Chamar um leitor não recalcula o resultado.

Sintaxe​

GetResultArray( "JSON++ Object", <index> )

Estrutura​

A referência implícita ao objeto seleciona uma instância. O argumento Integer seleciona uma posição da lista de resultados. Resultados numéricos podem alimentar ações numéricas diretamente; o exemplo usa Str$ somente para exibição no objeto String.

Parâmetros​

PosiçãoNomeTipoSignificado e restrições
1indexIntegerPosição com base zero na lista de resultados, não necessariamente um índice de elemento de array. Deve ser menor que a contagem de resultados armazenada.

Valor de retorno​

Retorna Text. O comportamento, o resultado do exemplo e o retorno em caso de falha são descritos abaixo.

Comportamento​

Serializa o resultado selecionado somente quando ele é um array. Os leitores nativos de valores tipados geralmente resolvem o caminho armazenado em relação ao JSON atual quando chamados. HTML5 mantém os caminhos de resultados e os valores ou referências coletados; substituir o documento posteriormente pode não atualizar esses valores coletados. Os leitores de chave, caminho e contagem podem devolver dados antigos quando o caminho do documento já não existe.

Exemplos​

Busca básica: o JSON inicial é {"bucket":{"match":["Potion","Key"]}}. Busque no objeto bucket seu membro chamado match e então leia a posição zero dos resultados.

Resultado esperado​

A busca do exemplo armazena uma correspondência em /bucket/match. O leitor exibe ["Potion","Key"]. Este cenário faz a leitura diretamente após a busca e dispensa a emissão do gatilho nativo de resultado de busca, ainda não esclarecida.

Erros e casos especiais​

O retorno alternativo nativo para índice inválido ou tipo incorreto é []; caminhos obsoletos podem informar um erro e então retornar []. HTML5 também usa [], lendo o valor de resultado coletado.

Limitações​

O retorno alternativo nativo para índice inválido ou tipo incorreto é []; caminhos obsoletos podem informar um erro e então retornar []. HTML5 também usa [], lendo o valor de resultado coletado. Novas buscas bem-sucedidas substituem o contexto de resultados. Uma busca com falha pode manter o resultado anterior; não confie em uma lista antiga como se fosse o resultado da última tentativa.

Compatibilidade entre plataformas​

A cobertura de execução entre exporters permanece incompleta. Use o comportamento e as limitações por runtime desta página ao escolher um destino. Consulte fluxos de arquivo por plataforma para I/O dependente do ambiente.
