E32 — Obter objeto do resultado

Descrição​

Serializa o resultado selecionado somente quando ele é um objeto.

Quando usar​

Leia após uma busca bem-sucedida ao inspecionar sua lista de resultados armazenada. Chamar um leitor não recalcula o resultado.

Sintaxe​

GetResultObject( "JSON++ Object", <index> )

Tipo de retorno do descritor: Text.

Estrutura​

A referência implícita ao objeto seleciona uma instância. O argumento Integer seleciona uma posição da lista de resultados. Resultados numéricos podem alimentar ações numéricas diretamente; o exemplo usa Str$ somente para exibição no objeto String.

Parâmetros​

PosiçãoNomeTipo do descritorSignificado e restrições
1indexIntegerPosição com base zero na lista de resultados, não necessariamente um índice de elemento de array. Deve ser menor que a contagem de resultados armazenada.

Comportamento​

Serializa o resultado selecionado somente quando ele é um objeto. Os leitores nativos de valores tipados geralmente resolvem o caminho armazenado em relação ao JSON atual quando chamados. HTML5 mantém os caminhos de resultados e os valores ou referências coletados; substituir o documento posteriormente pode não atualizar esses valores coletados. Leitores de chave, caminho e contagem podem retornar metadados armazenados mesmo quando o caminho do documento está obsoleto.

Exemplos​

Busca básica: o JSON inicial é {"bucket":{"match":{"name":"Alex"}}}. Busque no objeto bucket seu membro chamado match e então leia a posição zero dos resultados.

* Start of Frame
    JSON++ Object : Load JSON from string "{""bucket"":{""match"":{""name"":""Alex""}}}"
    JSON++ Object : Search for key "match" at "/bucket" (Exact: 1)
    String : Set alterable string to GetResultObject( "JSON++ Object", 0 )

Resultado esperado​

A busca do exemplo armazena uma correspondência em /bucket/match. O leitor exibe {"name":"Alex"}. Este cenário faz a leitura diretamente após a busca e dispensa a emissão do gatilho nativo de resultado de busca, ainda não esclarecida.

Erros e casos especiais​

O retorno alternativo nativo para índice inválido ou tipo incorreto é {}; caminhos obsoletos podem informar um erro e então retornar {}. HTML5 também usa {}, lendo o valor de resultado coletado.

Limitações​

O retorno alternativo nativo para índice inválido ou tipo incorreto é {}; caminhos obsoletos podem informar um erro e então retornar {}. HTML5 também usa {}, lendo o valor de resultado coletado. Novas buscas bem-sucedidas substituem o contexto de resultados. Uma busca com falha pode deixar o estado anterior, dependendo do ponto da falha; não presuma que uma lista antiga de resultados pertence à última operação tentada.
