Valores JSON, caminhos e estado

Objetos JSON contêm membros nomeados; arrays contêm elementos ordenados com índices a partir de zero. Strings, números, booleanos e null são tipos de valor distintos. "42" não é o número 42. O documento nativo usa a biblioteca JSON a ordem dos membros carregados; HTML5 usa objetos e arrays JavaScript e Number. A ordem dos objetos não é um contrato de dados portátil, especialmente para chaves JavaScript com aparência de inteiro.

Forma do caminhoSignificado no resolvedor nativoCuidado
/Raiz do documentoIr para o objeto raiz armazena uma representação diferente da raiz; consulte Ir para o objeto raiz.
/player/nameMembro aninhado absolutoA busca de membros diferencia maiúsculas e minúsculas.
/inventory/0Primeiro elemento do arrayOs índices mudam após remoção ou ordenação.
./statsRelativo ao cursor atualO cursor e a resolução relativa diferem em alguns casos HTML5.
../nameBusca relativa ao paiPercorrer acima da raiz informa um erro.
~1 dentro de um token do ponteiroCaractere / codificado em uma chaveEscape ~ como ~0; decodifique uma vez.

Um caminho vazio não é um alias universal para a raiz. O buffer de inserção tem uma rota separada de normalização de caminhos que pode aceitar entrada vazia como raiz. Use / explicitamente nos novos exemplos e siga o contrato de parâmetros de cada ação.

Um caminho nativo simples que não começa com / ou . é tratado por uma ramificação de token literal cujo ponteiro construído não tem a barra inicial; não dependa disso como atalho conveniente para uma chave na raiz. Use caminhos absolutos explícitos. Argumentos de chave separados nem sempre recebem escape pela mesma função auxiliar dos ponteiros completos; portanto, chaves contendo / ou ~ precisam de verificação específica por operação.

Cada instância mantém o JSON atual mais cursor e histórico, resultados de pesquisa, contexto de loop, configurações e referência de arquivo. Esses estados são relacionados, mas não idênticos. As consultas tipadas nativas usam funções auxiliares de leitura sem criar nós ausentes, mas várias escritas nativas podem criar destinos antes de um erro posterior.
