Iterate Over an Array

Goal​

Add the numbers in a scores array and display the total after completion.

Before you begin​

Add JSON++ Object and a visible String. Create a numeric global value named TotalScore. Read JSON loops first.

Step-by-step​

  1. Load the scores document at Start of Frame.
  2. In On JSON Loaded, reset TotalScore and start the Scores loop at /scores.
  3. In On loop Scores, add GetLoopValue for that name to TotalScore.
  4. Display the total in On end loop Scores. Add On Error and run the frame.

Example​

Default view

    • ●JSON++ Object: On JSON Loaded

    • Special : Add GetLoopValue( "JSON++ Object", "Scores" ) to TotalScore
    • ●JSON++ Object: On end loop "Scores"
    • String : Set alterable string to Str$(TotalScore)
    • ●JSON++ Object: On Error
    • String : Set alterable string to GetError( "JSON++ Object" )

Expected result​

The String displays 60 when the Scores loop finishes.

How it works​

Start Loop registers work. On Loop supplies a named current-item context. On End Loop is the completion point for the accumulated result. The current implementation prepares iteration from a snapshot; edits after starting the loop do not redefine that snapshot.

Important considerations​

Keep the loop name identical in its Action, Conditions and getters. Reading TotalScore immediately after Start Loop can precede completion. Use separate names for independent loops and review restart/stop behavior.
