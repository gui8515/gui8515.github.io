Introduction

Introduction to JSON++ Object​

JSON++ Object lets you load, read and change structured data through Clickteam Fusion 2.5 events. Keep a player's name, score and inventory together in a JSON document, then use Actions to change data and Expressions to read it.

What can you do?​

Organize player data

Group names, scores and inventory items in objects and arrays.

Load and inspect data

Read JSON text supplied by your events and display the document.

Understanding JSON​

{"player":{"name":"Alex","score":10},"inventory":["sword"]}
PartMeaning
playerAn object that groups a player's information.
"name": "Alex"A named member containing text.
"score": 10A named member containing a number.
inventoryAn array, an ordered list whose first item has index 0.
