Show Null Values

Description​

Controls the presentation of null members in Get JSON Text. Hiding null affects the returned display text while preserving the stored document. File serialization preserves null values so saving can retain the data.

Location​

Select JSON++ Object in the Frame Editor, open its Properties and choose Miscellaneous → Show Null Values.

Available values​

Enabled or disabled.

Default value​

false.

Platform notes​

Target-specific paths, storage, scheduling and exporter capabilities follow their runtime contracts. Configure and check the targets you distribute to.
