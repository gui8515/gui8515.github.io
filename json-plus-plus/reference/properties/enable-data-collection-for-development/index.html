Enable Data Collection for Development

Description​

A development-data-collection checkbox described by editor metadata.

When to Use​

There is no implemented property-controlled collection workflow in the inspected paths.

Syntax​

Properties editor: Miscellaneous → Enable Data Collection for Development.

Anatomy​

This is a Checkbox control. It is an editor setting copied into an exported object; it is not a Fusion expression. Descriptor position 31 is recorded for auditing, not presented as a stable public ACE identifier.

Parameters​

FieldDeclared value
Official nameEnable Data Collection for Development
Control typeCheckbox
Defaultfalse
OptionsNot applicable to this control
Numeric rangeNo explicit numeric range declared
PlaceholderNot declared

Behavior​

The native read is commented out and HTML5 initialization does not load this property. No behavior controlled by dataCollectionProp was established.

Evidence levels for this property:

  1. Declared in the editor descriptor: yes.
  2. Active initializer reads located: native no; HTML5 no. A read is not proof of an operational effect.
  3. Executable property-effect verification for this manual: not performed.

Examples​

Basic editor scenario: Toggle the checkbox in the editor.

This example describes configuration and inspected effects; it does not claim a validated MFA or exported-app test.

Expected Result​

No runtime collection behavior controlled by this setting is established.

Errors & Edge Cases​

No property-specific runtime validation or error response was established beyond the declared editor control. If the option is not consumed, its selection does not create the behavior promised by its label.

Limitations​

This is not an audit of unrelated network or telemetry code; the descriptor claims about collected data are not runtime evidence.
