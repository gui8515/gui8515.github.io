C13 — Is Object

Description​

Tests whether the selected JSON value is an object.

When to Use​

Use before reading or navigating named members of a record.

Syntax​

JSON++ Object: Is <path> an object?

Official descriptor caption: %o: Is %0 an object?. The object placeholder is not an input parameter.

Anatomy​

This is a state evaluation, not an event trigger. Fusion evaluates it whenever its enclosing event is evaluated; it may remain true across repeated evaluations. Loading the example establishes data, but no particular preceding Action is required if the document already has that state.

Parameters​

PositionNameDescriptor typeMeaning and constraints
1pathTextValue location as a JSON Pointer path; example /player.

Behavior​

Native uses is_object. HTML5 checks object type while excluding null and arrays. Empty objects qualify.

A normal missing path is not inserted into the native document by these read helpers. Invalid path resolution can still report an error. HTML5 has separate resolver/error behavior; do not infer that every false result emits or suppresses On Error identically.

Examples​

Basic scenario: load {"player":{"name":"Alex"}} and use the condition to gate the shown operation.

* Start of Frame
    JSON++ Object : Load JSON from string "{""player"":{""name"":""Alex""}}"

* JSON++ Object: Is "/player" an object?
    String : Set alterable string to GetString( "JSON++ Object", "/player/name" )

Expected Result​

The event reads Alex from the player record. The condition does not consume a trigger flag and can match again while the data remains unchanged.

Errors & Edge Cases​

An object type check does not verify that required keys exist or have the desired types.

Missing/incompatible values normally evaluate false for the native type/comparison predicates, except native Is Empty, which deliberately treats missing values as empty. Invalid pointer input and resolver error paths must be considered separately from a valid but missing member.

Limitations​

An object type check does not verify that required keys exist or have the desired types.
