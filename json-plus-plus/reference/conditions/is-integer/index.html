Integer

Description​

Tests the native stored integer category. The menu leaf is Integer under Is Number.

When to Use​

Use when native stored integer representation matters.

Syntax​

JSON++ Object: Is <path> an integer?

The object placeholder is not an input parameter.

Anatomy​

This is a state evaluation, not an event trigger. Fusion evaluates it whenever its enclosing event is evaluated; it may remain true across repeated evaluations. Loading the example establishes data, but no particular preceding Action is required if the document already has that state.

Parameters​

PositionNameTypeMeaning and constraints
1pathTextValue location as a JSON Pointer path; example /count.

Behavior​

Uses is_number_integer. HTML5 instead tests mathematical integrality with remainder modulo 1. A JSON token 1.0 is stored as floating-point natively but becomes an integral JavaScript Number; those predicates can disagree.

A missing path is not inserted into the document by these Conditions. Invalid path resolution can still report an error. On HTML5, it has separate resolver/error behavior; do not infer that every false result emits or suppresses On Error identically.

Examples​

Basic scenario: load {"count":3} and use the condition to gate the shown operation.

* Start of Frame
    JSON++ Object : Load JSON from string "{""count"":3}"

* JSON++ Object: Is "/count" an integer?
    Counter : Set counter to GetNumber( "JSON++ Object", "/count" )

Expected Result​

The count value 3 passes and is copied into the counter. The condition does not consume a trigger flag and can match again while the data remains unchanged.

Errors & Edge Cases​

This is not a portable bit-width, safe-integer, or signed-range test.

Missing/incompatible values normally evaluate false for the native type/comparison predicates, except native Is Empty, which deliberately treats missing values as empty. Invalid pointer input and resolver error paths must be considered separately from a valid but missing member.

Limitations​

This is not a portable bit-width, safe-integer, or signed-range test.
