E36 — Get Result Boolean

Description​

Returns 1 for a boolean true result, 0 for false or a nonboolean result.

When to Use​

Read this after a successful search when inspecting its stored result list. The result is not recomputed by calling a getter.

Syntax​

GetResultBoolean( "JSON++ Object", <index> )

Descriptor return type: Integer.

Anatomy​

The implicit object reference selects an instance. The Integer argument selects a result-list slot. Numeric results can feed numeric Actions directly; the example uses Str$ only for String display.

Parameters​

PositionNameDescriptor typeMeaning and constraints
1indexIntegerZero-based result-list slot, not necessarily an array element index. Must be below the stored result count.

Behavior​

Returns 1 for a boolean true result, 0 for false or a nonboolean result. Native typed-value getters generally resolve the stored path against the current JSON when called. HTML5 keeps both result paths and collected values/references; a later document replacement need not update those collected values. Key/path/count getters can return stored metadata even when its document path is stale.

Examples​

Basic search: initial JSON is {"bucket":{"match":true}}. Search the bucket for its member named match, then read result slot zero.

* Start of Frame
    JSON++ Object : Load JSON from string "{""bucket"":{""match"":true}}"
    JSON++ Object : Search for key "match" at "/bucket" (Exact: 1)
    String : Set alterable string to Str$( GetResultBoolean( "JSON++ Object", 0 ) )

Expected Result​

The example search stores one match at /bucket/match. The getter displays 1. This scenario reads directly after the search and does not require the unresolved native search-result trigger emission.

Errors & Edge Cases​

Zero is ambiguous between false, wrong type, invalid index, and some errors. This is not generic truthiness.

Limitations​

Zero is ambiguous between false, wrong type, invalid index, and some errors. This is not generic truthiness. New successful searches replace the result context. A failed search may leave older state depending on where it failed; do not assume that any old result list belongs to the latest attempted operation.
