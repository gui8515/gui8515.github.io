Convert INI to JSON

Description​

Parses key/value lines and section headings into a JSON object.

When to Use​

Import a small configuration using the common INI subset.

Syntax​

ConvertINItoJSON( "JSON++ Object", <inputText> )

Parameters​

PositionNameTypeMeaning and constraints
1inputTextTextINI text; a section heading is [section] and entries use the first = separator. No default argument is supplied.

Return Value​

Returns Text. The behavior, example result and error fallback are described below.

Behavior​

Trims lines, skips blank and ;/# comment lines, reuses repeated sections and converts finite numbers and recognized booleans. Empty values remain strings. HTML5 recreates repeated sections, converts an empty numeric value to 0, and does not explicitly skip comment lines containing =. Dotted section names stay literal; they do not reconstruct nested objects.

The expression converts its argument without replacing the instance's loaded JSON. To use returned JSON as the current document, explicitly pass the successful result to Load JSON from String. A fallback does not mean the conversion succeeded.

Examples​

Basic: convert a small player/configuration record and display the returned text.

Expected Result​

{"player":{"name":"Alex","active":true}}.

Errors & Edge Cases​

It reports conversion exceptions through On Error and returns {}. HTML5 catches conversion failures, logs a warning and returns the fallback; do not assume the same On Error contract.

Limitations​

CSV and INI cannot represent arbitrary JSON without loss. Keys, ordering, nulls, numeric-looking strings, quoting and nesting can change. Use JSON for lossless persistence.

Platform Compatibility​

Execution coverage remains incomplete across exporters. Use the runtime-specific behavior and limitations on this page when choosing a target. See platform file workflows for environment-dependent I/O.
