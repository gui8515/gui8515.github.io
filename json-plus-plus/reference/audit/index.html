A28 Advanced ChangeNative binding is type/path/key/value; hints and caption imply type/value/path/key. HTML5 uses numeric selectors and its array branch forwards value as both index and JSON text.The caption is misleading; a portable advanced contract is not established.

A23 Set BooleanNative descriptor is Integer and native treats nonzero as true; HTML5 parseBoolean requires true/false strings.Numeric-selector behavior is not established for an HTML5 export.
A26 Toggle BooleanNative sets a missing member to true; HTML5 requires the member to exist.Initialize members explicitly for consistent workflows.
Native setters versus HTML5Several native assignments can create destinations or use an empty key as the direct path; HTML5 setters require an existing parent and nonempty key.Missing-data and empty-key behavior is operation-specific.
Numeric addition/subtractionNative has finite-value and checked int64 branches; HTML5 uses JavaScript Number arithmetic.Precision and overflow behavior differ.
PropertiesMany declared fields have commented-out native reads or no runtime effect. Some HTML5 reads exist where native reads are disabled.Every property page separates declaration, loading, and executed evidence.

Executed checks and evidence limits​

The documentation auditor checks descriptor IDs, parameter types/order, property indices, required nonempty sections, compatibility vocabulary, JSON blocks/Fusion JSON literals, links, anchors, and index reachability. It reports remaining pages independently from errors.

Existing checks executed for this documentation work:

  • node tests.dev/test_compatibility.js: passed; protects the existing descriptor contracts (203 positional ACE slots and 46 property records).
  • node tests.dev/test_property_headers.js: passed; DAR1/DAR2 property reader checks and mocked HTML5 initialization for selected fields.
  • node tests.dev/test_immediate_default.js: passed; simple insertions, default Immediate mode, hidden commit metadata, and legacy buffered commit in a Node sandbox.
  • node DarkEdif/JSONPlusPlus/tests.dev/test_smoke.js from repository root: passed; error state and one-time consumption of the HTML5 On Error flag in a Node sandbox.

Additional scoped checks passed: node docs/tools/verify_examples.cjs (72 documented HTML5 cases: Conditions, Expressions, and completed-root-fragment normalization), python tests.dev/tools-verificar-caminhos-t9.py (native path/query extraction harness), and python tests.dev/tools-regressao-nativa.py (existing native regression harness, TOTAL_FAILURES=0; captured log).

The Node tests do not validate Fusion exports, actual browser integration, native execution, or every property effect. Platform cells remain Not Tested where target-runtime evidence has not been collected. All 206 individual references are present and the complete static gate passes. Introductory material, seven practical guides, concepts, templates and glossary are available. See the acceptance audit. This is documentation completion, not homologation of every target.

Additional implementation findings​

EntriesFinding and practical consequence
A29/A30HTML5 resolves full values and then indexes by final tokens again; native full-path move/copy recipes are not portable. Native Move stages a document copy.
A32Native rejects rename collisions and preserves identity rename. HTML5 overwrites collisions and can delete an identity-renamed member.
A33–A35Normal loops are scheduled. Native live iterators prohibit safe structural mutation; SetLoopIndex rejects asynchronous registrations and is not a portable seek.
A36–A43Cursor/history/event behavior differs; native advanced mode is ignored, HTML5 expects numeric modes despite Text metadata. Native GoToRoot stores a library pointer to an empty-name member rather than the empty pointer.
A44–A46Case matching, result lifetimes and event emission differ. HTML5 advanced search selectors and helper argument positions conflict with the descriptor/caller.
A47–A51Key sort of arrays is lexical. Native advanced recursion traverses without sorting descendants. HTML5 advanced object sorting can replace currentPath instead of the requested target.
A52–A55Recursive top-level array/scalar replacement differs in HTML5. Patch is not fully RFC7396-conformant for newly assigned nested objects. HTML5 self-union of an array can grow without bound.
A58/A59Native staging/replace differs from asynchronous browser schemes. Success events are not universal durability guarantees.
C33–C69Triggered metadata includes flag predicates. Native change/search callback truth is not proof that corresponding events are emitted; HTML5 currentEventId and fallback consumption differ.
E19–E28/E32–E41Loop getter gating is based on parent container flags. Native search getters reread current paths; HTML5 retains collected values/references.
E44–E53BSON/XML/YAML have guarded conversion contracts. CSV/INI parsing, coercion, quoting and nesting differ and are not lossless general formats.
A60–A72Many setters only change flags; A69 native is a no-op. A72 is hidden legacy, default insertion is Immediate, and commit is not transactional.

The additional executed evidence is indexed in Examples: 57 context scenarios, 24 workflow assertions, 65 existing settings/legacy assertions and 168 BSON/XML/YAML checks. The original native regression log records TOTAL_FAILURES=0. Tests do not validate unexecuted exports or justify broad Supported cells.

Source provenance and maintenance​

Audited implementation files have no diff from code commit df95b0245e0fe6e316d31c828def6c1ffeec601e. Current documentation also includes local changes; no release version is inferred from that commit. Shared native source is not proof of identical Android/macOS/iOS SDK integration. Known Windows/HTML5 availability does not establish exported behavior.

Future releases should rerun the static gate and scoped examples, then collect versioned Fusion/export evidence for the intended targets. Treat documented implementation defects as separate engineering work. Do not silently repair the runtime while updating this manual.
